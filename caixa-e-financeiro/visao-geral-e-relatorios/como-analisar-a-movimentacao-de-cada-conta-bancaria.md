# Como ver a movimentação de cada conta bancária

{% hint style="warning" %}
🔧 **Nota interna – remover antes de publicar:** texto escrito a partir do vídeo. Conferir na tela do sistema os trechos marcados [confirmar na tela].
{% endhint %}

Use o filtro de contas bancárias do Painel financeiro para ver tudo o que entrou e saiu de cada conta corrente e conferir com o seu banco.

{% hint style="info" %}
**Antes de começar:** só aparecem no filtro as contas cadastradas em **FINANÇAS > CONTAS BANCÁRIAS > CADASTRAR CONTA CORRENTE**.
{% endhint %}

## Passo a passo

1. Acesse **FINANÇAS > PAINEL FINANCEIRO**.
2. Escolha a visualização **por mês** ou **por dia**.
3. Selecione a **conta corrente** que deseja analisar.
4. Clique na **pastinha amarela** de um dia para ver o detalhamento das movimentações.

## Entendendo a tela

* **Venda à vista:** valores que caem na hora, como PIX, TED e **débito**. O débito aparece aqui mesmo que o depósito seja no dia seguinte.
* **Cartão de crédito:** o que a maquininha depositou naquele dia, não as vendas feitas no dia. Uma venda de 30 dias atrás pode aparecer hoje.
* **Crediário:** apenas os **recebimentos** de parcelas nessa conta, nunca a venda.
* **Fornecedores e despesas:** quanto foi pago a partir dessa conta.
* **Totais:** soma das entradas e saídas do período.

{% hint style="warning" %}
Os valores de cartão são **brutos**. Para ver o valor líquido, cadastre a taxa da maquininha em **VENDAS > CONTAS A RECEBER > CARTÕES** [confirmar na tela].
{% endhint %}

{% hint style="warning" %}
O sistema não registra transferências entre contas. Se você mover dinheiro de uma conta para outra, o saldo pode não bater exatamente com o banco. O filtro também não mostra o caixa físico, apenas contas correntes.
{% endhint %}

## 🎬 Vídeo

Para auxiliar na conciliação bancária, acesse a tela **FINANÇAS > PAINEL FINANCEIRO** para visualizar as entradas e saídas do dia por conta bancária cadastrada.
