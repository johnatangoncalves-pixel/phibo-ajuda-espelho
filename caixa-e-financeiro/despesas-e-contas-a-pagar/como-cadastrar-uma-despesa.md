# Como lançar uma despesa (passo a passo com imagens)

{% hint style="info" %}
🔧 **Nota interna (D08) – remover antes de publicar:** conteúdo repetido com [Como cadastrar uma despesa](como-cadastrar-uma-despesa-2.md). Juntar os dois e manter só um.
{% endhint %}

Para ver o passo a passo completo, assista ao vídeo abaixo para cadastrar uma despesa no sistema Phibo:

{% embed url="<https://www.loom.com/share/e3a755c823834137a71d7f44e671aa87>" %}

1 - Para realizar o cadastro de uma despesa no sistema, vá em **FINANÇAS > CADASTRAR DESPESAS**:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F6lr51tl0OHMGY9qZNOur%2Fimage.png?alt=media&amp;token=40e10cdd-399e-4580-8f27-f73db94c5e75" alt=""><figcaption></figcaption></figure>

2 – Em seguida clique no botão no canto direito da tela NOVA DESPESA:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F9Q3r2d8vprhC18f4THFD%2Fimage.png?alt=media&amp;token=e1ab36bd-46b2-4e5c-b004-3070c43d0aa0" alt=""><figcaption></figcaption></figure>

3- Na tela a seguir, preencha todos os campos com as informações da Despesa em questão:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FKcns8Fuq5KNhfFdOdL8P%2Fimage.png?alt=media&amp;token=f4bb3d98-6cde-4b92-a736-e3d409115d42" alt=""><figcaption></figcaption></figure>

O campo **Classificação** serve para definir qual tipo de despesa você está cadastrando no momento.

{% hint style="info" %}
Se quiser incluir ou editar alguma classificação nas opções, vá em **FINANÇAS > CADASTRAR CLASSIFICAÇÃO**.
{% endhint %}

Depois coloque no cadastro a **Descrição** (nome da despesa), o **valor** a pagar e a **data de vencimento** (data máxima que você pode realizar o pagamento dessa despesa).

\
O campo **Ciclo de Pagamento** é referente à recorrência dessa despesa.

* **Mensal:** essa despesa será replicada em todos os meses seguintes.
* **Eventual:** o sistema fará somente 1 cadastro dessa despesa.
* Se selecionar as demais opções, o sistema repetirá essa despesa de acordo com o número de parcelas selecionadas.

4- Depois que os dados estiverem devidamente preenchidos, clique em "Salvar" e a despesa será cadastrada.

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FNQMpXuhh6BpEVc3piX4y%2Fimage.png?alt=media&amp;token=3881660b-2646-41e7-acc8-fca92eb33de1" alt=""><figcaption></figcaption></figure>
