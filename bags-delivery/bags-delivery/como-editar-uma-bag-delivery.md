# Como editar uma bag

{% hint style="info" %}
🎬 **Vídeo em atualização.** Estamos regravando o vídeo deste tutorial e em breve ele estará disponível aqui.
{% endhint %}

Para editar uma bag aberta, primeiro vá em **VENDAS > BAG > MONTAR BAG**

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2Fqb8ph1yvCkgygR68N6YZ%2FWhatsApp%20Image%202025-12-31%20at%2014.08.12.jpeg?alt=media&amp;token=25397291-1fd0-4859-ac9b-45134763aa87" alt=""><figcaption></figcaption></figure>

Após acessar essa tela, você deve clicar no botão *EDITAR BAG ABERTA*

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F7yDYSOSRwqQywJFKS6L8%2FWhatsApp%20Image%202025-12-31%20at%2014.09.18.jpeg?alt=media&amp;token=1363d04c-3863-4cd1-a158-4e71db9bd424" alt=""><figcaption></figcaption></figure>

Agora é só buscar a BAG que deseja editar pelo nome do cliente ou pelo número dele. Após encontrar, é só selecionar no vezinho verde

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FusxMa63KgQEOlKnqYqtd%2FWhatsApp%20Image%202025-12-31%20at%2014.19.04.jpeg?alt=media&amp;token=3572630c-5858-4e70-a475-f6f4ddc88e06" alt=""><figcaption></figcaption></figure>

A bag retornará para a tela de cadastro, onde você poderá fazer as alterações desejadas. Após as alterações serem feitas, é só clicar no botão *CONCLUIR MONTAGEM DA BAG* e ela será atualizada corretamente.

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FaXXL05Os3VC3lgQQ53Km%2FWhatsApp%20Image%202025-12-31%20at%2014.23.56.jpeg?alt=media&amp;token=281fe6fe-452f-4d53-863d-7eb8e3588c39" alt=""><figcaption></figcaption></figure>

Quando já tiver sido feita alguma movimentação na bag (ou seja, venda ou retorno de peça), ela não aparecerá ao buscar no botão *EDITAR BAGS ABERTAS*. Nesse caso, é necessário abrir novamente a bag acessando a tela *VENDAS > **BAG > RETORNO DE BAG**.*

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2Fw81ITUhK0vGpvjaTaUsV%2FWhatsApp%20Image%202025-12-31%20at%2014.32.01.jpeg?alt=media&amp;token=2093e22e-84ab-425c-afef-23256e877422" alt=""><figcaption></figcaption></figure>

Agora, para abrir a bag, basta buscar a bag desejada e clicar no carrinho de compras. Vai abrir uma tela com a mensagem *PERMITIR NOVA VENDA PARA BAG*. É só confirmar, e assim essa bag ficará aberta novamente para que você possa seguir os passos acima de edição de bags abertas.

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FzPARmnd1JSaTXsAAjq09%2FWhatsApp%20Image%202025-12-31%20at%2014.34.42.jpeg?alt=media&amp;token=d24be2c1-70d7-4bfe-8492-d61506924fd8" alt=""><figcaption></figcaption></figure>

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FDpsu8snjfd1milmtl1bx%2FWhatsApp%20Image%202025-12-31%20at%2014.35.48.jpeg?alt=media&amp;token=1fd3e9b3-a18b-455d-bb76-0148bf9376b8" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
Quando um produto é excluído de uma bag, automaticamente o registro dele na bag é removido, junto com a informação de que aquele produto fez parte da bag no histórico dele
{% endhint %}
