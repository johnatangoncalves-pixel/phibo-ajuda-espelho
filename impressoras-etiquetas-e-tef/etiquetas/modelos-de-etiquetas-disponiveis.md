# Modelos de etiquetas disponíveis

{% hint style="info" %}
**IMPORTANTE:**  Para realizar a impressão de etiquetas, você vai precisar de uma  impressora compatível com o sistema. Seguem abaixo os modelos:

* Argox OS-214 PLUS
* Argox OS-2140 PPLA (OBS\* É necessário ser linguagem PPLA)
* Elgin L42 PRO
* Elgin L42 PRO FULL
  {% endhint %}

### Atualmente existem 2 modelos de etiquetas compatíveis com o sistema Phibo (para impressão) e 1 modelo já impresso. Veja nesse artigo os detalhes e especificidades de cada um e descubra qual seria o melhor para sua loja! 😉

## Etiqueta Dupla Master

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FOOUoNFwBIq5ZoElSyeY6%2Fimage.png?alt=media&amp;token=43fd8efb-2f7a-4b4c-b4ef-c186727cd97a" alt=""><figcaption></figcaption></figure>

### Esse modelo possui o tamanho **50x70mm**, separada em 2 colunas, ou seja, com 2 etiquetas por fileira.

### Cada rolo vem com 1000 etiquetas!

### É um modelo apropriado para etiquetar roupas e ideal para o uso com aplicador de tags, por conter o furo em sua extremidade (pode ficar pendurada na tag).

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F9bCS9ZXzJA05ePWsJ4AY%2Fduplamaster2.jpg?alt=media&amp;token=d9e03eb5-86d1-4fa6-90af-98d91148b76d" alt=""><figcaption></figcaption></figure>

### Nela ficam informados:

* O nome da loja
* Descrição do produto
* Código de barras
* Código Refrência
* Cor do produto
* Tamanho
* Prazo de troca
* Valor do produto

### Ela tem 3 partes destacáveis, onde é possível destacar tanto o preço quanto o código de barras (ideal para produtos quer serão dados de presentes ou para lojistas que retém o código na loja para controle de saída das peças).

## Etiqueta Tripla Master

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FEzl68Ai9DJqfyUHJ37ZZ%2Fimage.png?alt=media&amp;token=5ea104ae-599e-4d10-92af-77012faf08bb" alt=""><figcaption></figcaption></figure>

### Possui o tamanho **33x21mm**, separada em 3 colunas, ou seja, com 3 etiquetas por fileira.

### Cada rolo vem com 3000 etiquetas.

### É um modelo menor de etiquetas, porém mais econômico. As etiquetas são adesivadas, podendo ser coladas diretamente nas tags de seus produtos.

### Nela ficam informados:

* Descrição do produto
* Cor
* Grade
* Código de barras
* Código referência
* Valor

## Etiqueta de Semi Joias

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FY0H8mM770qpsG2OWk4y9%2Fimage.png?alt=media&amp;token=0d265535-6c23-4606-87bf-819a01b8e2d3" alt=""><figcaption><p>M<strong>odelo 82x11mm</strong></p></figcaption></figure>

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F2mYNgKLy9gTRokURydFg%2Fimage.png?alt=media&amp;token=c4c2404f-b99a-4d80-bf2e-0222827baf07" alt=""><figcaption><p><strong>Modelo 95x15mm</strong></p></figcaption></figure>

### Seu tamanho pode ser 82x11**mm ou 95**x15mm, esse modelo é indicado para produtos como joias, acessórios e semi joias pois, ele possui **um adesivo dobrável que se enrosca na peça, sendo ideal para exibir preços e códigos de barras sem comprometer a apresentação do produto.**

### Cada rolo vem com 1000 etiquetas.

### Nela ficam informados:

* Código de barras
* Código referência
* Valor
