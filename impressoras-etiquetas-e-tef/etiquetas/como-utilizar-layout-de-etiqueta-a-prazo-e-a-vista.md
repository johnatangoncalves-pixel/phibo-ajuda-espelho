# Como usar layout de etiqueta a prazo e a vista

{% hint style="warning" %}
🔧 **Nota interna – remover antes de publicar:** texto escrito a partir do vídeo. Conferir na tela do sistema os trechos marcados [confirmar na tela].
{% endhint %}

Use o layout de etiqueta à vista e a prazo para imprimir os dois preços na etiqueta do produto.

{% hint style="info" %}
**Antes de começar:** este layout não está disponível para todos. Depende da impressora, da etiqueta e do plano contratado. Confirme com o suporte se você pode usá-lo. Também peça ao suporte para ativar o **percentual de desconto à vista** (por exemplo, 10%), que vale para todos os produtos.
{% endhint %}

## Passo a passo

### Cadastrar o produto

1. Cadastre o produto normalmente.
2. No campo **Valor de venda**, informe sempre o **valor cheio, a prazo**. O sistema calcula o valor à vista com o desconto configurado.

### Configurar o layout

1. Acesse **INÍCIO > CONFIGURAR MÓDULOS > GESTÃO DE IMPRESSÃO** [confirmar na tela].
2. Escolha o layout de **à vista e a prazo** (pode aparecer como "à vista / cartão"). As opções variam conforme a impressora e o plano.
3. Clique em **Salvar**.

### Imprimir as etiquetas

1. Acesse **COMPRAS > GESTÃO DE ESTOQUE > LISTAR PRODUTOS**.
2. Ative o modo de impressão clicando no **botão vermelho**.
3. Encontre o produto (por exemplo, pela opção **Últimos X cadastrados**), selecione e clique em **Adicionar à fila de impressão**.
4. Clique em **Gerar etiquetas** e baixe o arquivo.

{% hint style="warning" %}
Se alguns produtos usam outro percentual (por exemplo, 15%), imprima primeiro todos os de 10%. Depois peça ao suporte para trocar o percentual e imprima os demais.
{% endhint %}

### Vender à vista

1. Ao bipar a etiqueta no PDV, o sistema sempre traz o **valor a prazo**.
2. Se o cliente pagar à vista, clique em **Efetuar recebimento** e use **Adicionar plano de desconto** [confirmar na tela] com o percentual à vista.
3. Confirme e finalize a venda.

{% hint style="info" %}
Para criar o plano de desconto, veja o tutorial específico ou peça ajuda ao suporte.
{% endhint %}
