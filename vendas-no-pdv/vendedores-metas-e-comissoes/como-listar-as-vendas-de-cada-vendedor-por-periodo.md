# Como listar as vendas de cada vendedor por período

Para consultar os detalhes das vendas feitas por um vendedor, você poderá ir em VENDAS > VENDEDORES > LISTAR VENDAS:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FdKkDVqprUEHeOH9xadNh%2Fimage.png?alt=media&amp;token=7dfab88c-c49a-4cef-90b3-3016492fea8a" alt=""><figcaption></figcaption></figure>

Depois, informe o período destacado na imagem abaixo, para carregar os registros dos vendedores.

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FWDJqXDRM9heUsc6ir7g2%2Fimage.png?alt=media&amp;token=b804ec34-c9c9-45e5-97c1-2e70ce0b3fe2" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Utilize o ícone à esquerda, destacado na imagem, para abrir o detalhamento de cada venda do vendedor selecionado.
{% endhint %}
