# Como cadastrar um vendedor

Assista abaixo, o passo a passo completo para cadastrar um vendedor:

{% embed url="<https://www.loom.com/share/3afe1b355c3b435caf36fb845a6b0617>" %}

{% hint style="info" %}
**IMPORTANTE: Os campos de preenchimento obrigatório são os campos em** **vermelho**.\
Os campos em preto, não é necessário preencher se não quiser.
{% endhint %}

1° - Para cadastrar um vendedor, primeiro vá em VENDAS > VENDEDORES<br>

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FUo0XQtRM7zQ8rAcdyFx9%2F1.png?alt=media&amp;token=c7ac1de0-1e10-44f6-a169-52ffb7c90bb8" alt=""><figcaption></figcaption></figure>

2° - Clique em NOVO VENDEDOR

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FWu1KW7UDVIGjLUZtSkWK%2Fimage.png?alt=media&amp;token=a00c1263-fab0-4aae-988a-6f526d08a2fc" alt=""><figcaption></figcaption></figure>

3° - Defina o nome do vendedor e o percentual da sua comissão:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FK3V58mjj5vNb8sftGPNe%2Fimage.png?alt=media&amp;token=423762b7-5f23-4211-9100-59735111ceab" alt=""><figcaption></figcaption></figure>

\
\* Nome completo: é o nome completo do vendedor, (esse é um campo obrigatório)

\
\* Nome abreviado: é o apelido do vendedor, como ele prefere ser identificado (esse é um

campo obrigatório)

\
\* Comissão: é o percentual de comissão que ela ganhará sobre o valor vendido

\
\* Bônus: é a premiação que o vendedor ganha por bater a meta. Basicamente você definirá quanto ele ganhará por bater a meta.

\
![](https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FBNiq7DlbuxfjJ8it9jnB%2Fimage.png?alt=media\&token=0e952563-c4c1-43c2-b905-8ceb3625a39e)

No exemplo da imagem, o vendedor ganha 150,00 se bater 100% da meta.

\
\* Apontar usuário para vendedor: Nessa função você vincula o usuário que aquele vendedor faz login para que ao acessar, ele veja apenas as vendas dele.

4° - Por fim, clique em SALVAR
