# Como fazer uma venda para um cliente sem cadastro

{% hint style="warning" %}
🔧 **Nota interna – remover antes de publicar:** texto escrito a partir do vídeo. Conferir na tela do sistema os trechos marcados [confirmar na tela].
{% endhint %}

Veja como registrar uma venda quando o cliente não quer ou não pode informar os dados dele.

{% hint style="warning" %}
O sistema não permite registrar a venda sem informar um cliente.
{% endhint %}

## Passo a passo

### Cadastro rápido do cliente

1. Acesse **PDV > REGISTRAR VENDA** e selecione o vendedor.
2. Clique em **Incluir cliente** e preencha só o básico: nome, sexo e telefone.
3. Salve. O cliente já entra automaticamente na venda.

### Usar o cliente padrão

Se o cliente não quiser passar nenhuma informação, use um **cliente padrão**, criado só para esse tipo de venda.

1. Para criar, acesse o cadastro de clientes [confirmar na tela] e preencha:
   * **Telefone:** 0 (zero).
   * **Nome:** "Cliente padrão" ou "Consumidor final".
   * **Nome abreviado:** "Padrão".
   * **Sexo**, **como conheceu** e **data de aniversário:** qualquer opção (de preferência uma data que não exista de verdade).
2. Salve o cadastro.
3. Na venda, busque o cliente pelo telefone **000**, adicione os produtos, clique em **Efetuar recebimento**, escolha a forma de pagamento e conclua.

{% hint style="warning" %}
Como o cliente padrão não tem telefone válido, o comprovante não pode ser enviado por WhatsApp, apenas impresso. Nos relatórios, a venda fica no nome do cliente padrão, e você não terá esses dados para campanhas.
{% endhint %}

Sempre que possível, cadastre seus clientes. Oferecer o cartão fidelidade é uma boa forma de incentivar o cadastro.
