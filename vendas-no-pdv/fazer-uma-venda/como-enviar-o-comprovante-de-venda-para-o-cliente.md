# Como enviar o comprovante de venda para o cliente

Envie o cupom de venda ou a nota fiscal para o cliente pelo WhatsApp, de forma manual pela integração do sistema ou de forma automática pelo PhiboZap.

## Passo a passo

### Envio manual pela integração do sistema

**Ao concluir uma venda:**

1. Acesse **VENDAS > PDV REGISTRAR VENDA**, selecione o cliente e os produtos.
2. Clique em **EFETUAR RECEBIMENTO**, escolha a forma de pagamento e clique em **CONCLUIR VENDA**.
3. Nos ícones que aparecem, clique no de **download** para baixar o PDF do cupom.
4. Clique no ícone do **WhatsApp** e em **Abrir o WhatsApp**. A mensagem configurada já vem preenchida.
5. Envie a mensagem e, em seguida, anexe o cupom baixado.

**Depois da venda:**

1. Acesse **VENDAS > RELAÇÃO DE VENDAS** e selecione a data.
2. Clique no ícone do cupom. O PDF abre; faça o download e salve.
3. Clique no ícone do **WhatsApp**, envie a mensagem e anexe o cupom.

{% hint style="warning" %}
Na integração básica, o arquivo sempre precisa ser baixado e anexado manualmente. Isso vale também para o romaneio de bag. O envio com o cupom já dentro da mensagem só acontece pelo PhiboZap.
{% endhint %}

### Envio automático pelo PhiboZap

1. No PhiboZap, acesse **Mensagens** e vá até a última página (ou penúltima). Lá estão as mensagens padrão de **Cupom de venda**, **Nota fiscal** e **Comprovante de pagamento**.
2. Para editar o texto, clique na mensagem. Se quiser, use **Adicionar item > Cartão fidelidade** para enviar também os selos do cliente.
3. Acesse **Campanha** e encontre a campanha desejada.
4. Clique no ícone de **papel e caneta** para editar.
5. Ative o **Envio automático** e salve.

Pronto: ao concluir a venda, o sistema envia o cupom ou a nota sozinho. Na campanha de comprovante de pagamento, o comprovante é enviado assim que você recebe uma parcela do crediário.

{% hint style="info" %}
Você pode ativar o cupom e a nota ao mesmo tempo, mas avalie para não enviar mensagens demais. Se a loja trabalha com crediário, prefira o cupom de venda, pois ele traz o detalhamento das parcelas.
{% endhint %}
