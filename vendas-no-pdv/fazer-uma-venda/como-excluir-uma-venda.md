# Como excluir uma venda

Para excluir uma venda é só seguir os passos a seguir.

{% embed url="<https://www.loom.com/share/48a245989aed4c71a471c5010bfb68c3>" %}

O primeiro passo para excluir uma venda e entra em **VENDAS > RELAÇÃO DE VENDAS**.

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F1yr0l0umbLcHCTKNMkXF%2FWhatsApp%20Image%202024-02-24%20at%2012.41.46.jpeg?alt=media&amp;token=922e3175-0dc0-401c-b590-af2d88d0b1b0" alt=""><figcaption></figcaption></figure>

Assim que acessar a tela busque pelo dia que foi realizado a venda

{% hint style="warning" %}
Apenas a aba de DIA DA VENDA possui a opção de excluir a venda
{% endhint %}

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FIK2BpYjcNcjLSg26DYFg%2Fimagem_2024-02-24_125442282.png?alt=media&amp;token=de28d3fc-4451-4bbe-bc4e-4be4d6dc5e6c" alt=""><figcaption></figcaption></figure>

Assim que for selecionado o dia correto, encontre a venda que deseja excluir, e aperte no símbolo da lixeira.

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FR49AegY96euaQbw87Cmp%2Fimagem_2024-02-24_130136913.png?alt=media&amp;token=c90ae447-f676-4b8a-bd58-712f16b89109" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
ATENÇÃO: Quando uma venda COM NOTA FISCAL for EXCLUÍDA a nota fiscal referente essa  venda também será CANCELADA automaticamente SE ainda estiver dentro do prazo .

Prazos:

Modelo NFC-e  65: 30 minutos

Modelo NF-e modelo 55: 24 horas
{% endhint %}
