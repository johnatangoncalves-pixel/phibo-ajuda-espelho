# Como configurar e usar os Cupons de Desconto nas vendas

{% hint style="warning" %}
IMPORTANTE: Somente os usuários dos planos Prata e Ouro têm acesso à função de criação e uso dos Cupons de Desconto
{% endhint %}

#### Para visualizar o passo a passo completo, assista o vídeo abaixo ou leia detalhadamente o tutorial de como criar e utilizar os cupons de desconto:

{% embed url="<https://www.loom.com/share/44c32ad456d44e4b8979e2903a5a1bd1>" %}

#### 1 - Antes de tudo, é necessário criar o seu cupom. Para isso, vá em INÍCIO > CONFIGURAR MÓDULOS > CUPOM DE DESCONTO.

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F4K1Q8cVTbmM5jS07xQjc%2Fimage.png?alt=media&amp;token=bc454ef7-297e-4bc6-a557-0856453ba8fc" alt="" width="274"><figcaption></figcaption></figure>

#### 2 - Nessa tela, clique em NOVO CUPOM:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FvpW0G1KpCvCeE62zBzsU%2Fimage.png?alt=media&amp;token=f6689722-c6d4-4919-9f53-cecd4e282f58" alt="" width="375"><figcaption></figcaption></figure>

#### 3 - Nessa tela, defina os campos obrigatórios: 

* **O código:** É o "nome" do seu cupom. Ex: NOMEDOCLIENTE+VALOR = MARIA20;
* **Valor do Cupom:** Defina se o valor do cupom será em porcentagem na venda ou em valor fixo (ex: 20% ou 20 R$);

E caso queira (não são obrigatórios), pode colocar algumas limitações, como:

* **Quantidade permitida de usos:** Se o cliente pode usar o cupom só uma vez ou várias vezes;
* **Valor mínimo:** Serve para definir se para usa-lo o cliente precisa gastar algum valor mínimo na compra. Ex: o cupom só vale para compras acima de 30 reais;
* **Data:** Onde você define se o cliente terá algum limite de tempo pra usar o cupom antes que ele expire ou se pode usá-lo por tempo indefinido.
