# Como criar uma promoção

{% embed url="<https://www.loom.com/share/de1fc42e911542bb92ad8a2feaa131ce>" %}

## 1- Para criar um evento promocional e reduzir o valor de peças selecionadas, acesse **INICIO > CONFIGURAR MÓDULOS > PROMOÇÃO:**

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2Fs4Z6OxRUuFM8RuHXMIrc%2FPROMO.jpg?alt=media&amp;token=964b4c85-960c-4de2-9ec3-ca91d95b09f2" alt=""><figcaption><p>Se essas opções não aparecem para você, acesse com o usuário administrador.</p></figcaption></figure>

## 2 - Clique em NOVA PROMOÇÃO para criar um novo evento:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FFP8wkJc2SvaOSopnOidD%2Fimage.png?alt=media&amp;token=671e8131-c250-4768-a133-3c19bb283b9b" alt=""><figcaption></figcaption></figure>

## 3 - Defina o nome da promoção, o período que ela vai ficar ativa e o percentual de desconto que deseja aplicar:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FZDadfopxGEO4qoHvRVC3%2Fimage.png?alt=media&amp;token=a39924b6-d447-4b16-9b09-851fbf6e4430" alt=""><figcaption></figcaption></figure>

## 4-No campo "APLICAÇÃO", escolha um filtro para selecionar os produtos que ficarão com o valor promocional e salve:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FheLxqz5JMqVC9eppWFeO%2Fimage.png?alt=media&amp;token=8eff4f9f-24ba-4c4b-80c1-8da3fce989f5" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Para escolher produtos aleatórios, selecione a opção "PRODUTOS ESPECÍFICOS" e salve. Ao finalizar basta clicar ícone com três barrinhas para selecionar os produtos:
{% endhint %}

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F57U2wnJM137ZLj0Jz4Kf%2Fimage.png?alt=media&amp;token=2b6d3e67-0316-4116-8e1f-e763e0991db5" alt=""><figcaption></figcaption></figure>

## 4 - Promoção criada! Para editar clique no ícone do papel com o lápis e, para exclui-la clique na lixeira:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FuSBtXtEVnidI6UoCyOK7%2Fimage.png?alt=media&amp;token=4b19f1db-f84f-4fa5-8014-0f43fb1a04a3" alt=""><figcaption></figcaption></figure>

## 5 - Prontinho! Até o fim da promoção, sempre que algum produto escolhido no evento promocional for selecionado, seu desconto será aplicado de forma automática:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FIAE3li7JziIlEijFY9YI%2Fimage.png?alt=media&amp;token=d185607b-2823-4943-b1e0-c2413ddd47c5" alt=""><figcaption></figcaption></figure>
