# Como lançar um crediário com vencimento semanal ou quinzenal

{% hint style="warning" %}
🔧 **Nota interna – remover antes de publicar:** texto escrito a partir do vídeo. Conferir na tela do sistema os trechos marcados [confirmar na tela].
{% endhint %}

Veja como lançar uma venda no crediário com parcelas semanais, quinzenais ou em datas livres, sem seguir o vencimento de mês em mês.

## Passo a passo

1. Acesse **VENDAS > REGISTRAR VENDAS** [confirmar na tela].
2. Selecione o **vendedor**, o **cliente** e os **produtos**.
3. No recebimento, escolha **Crediário** e lance **uma parcela** com a data do primeiro vencimento e o valor que o cliente vai pagar nesse dia.
4. Escolha **Crediário** de novo e lance a segunda parcela, com a nova data e o valor.
5. Repita para cada parcela até completar o valor total da venda.
6. Conclua a venda.
7. Imprima o comprovante e entregue ao cliente.

Exemplo: para três parcelas semanais, lance uma parcela para o dia 16, outra para o dia 23 e outra para o dia 30.

{% hint style="info" %}
Você define a data e o valor de cada parcela. As datas não precisam ter o mesmo intervalo entre si, e os valores podem ser diferentes.
{% endhint %}

{% hint style="warning" %}
Lance uma parcela por vez, cada uma com quantidade **1** e a data de vencimento correta.
{% endhint %}
