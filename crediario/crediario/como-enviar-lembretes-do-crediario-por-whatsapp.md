# Como enviar lembretes do crediário por WhatsApp

Envie lembretes de cobrança do crediário pelo WhatsApp usando a integração básica, que já vem no seu plano. O envio é individual e manual, um cliente por vez.

{% hint style="info" %}
**Antes de começar:** se quiser que as cobranças sejam enviadas automaticamente, é preciso contratar o PhiboZap. Fale com o suporte.
{% endhint %}

## Passo a passo

### Personalizar a mensagem de cobrança

1. Acesse **CLIENTES > MARKETING > WHATSAPP**.
2. Se a mensagem de **Cobrança de crediário** já existir, clique nela para editar. Se não existir, clique no botão verde no alto da tela para incluir uma nova.
3. Escreva o texto e salve.

{% hint style="warning" %}
A mensagem deve ter só texto. Emojis e links (como o do seu Instagram) não são aceitos e a mensagem não será salva.
{% endhint %}

### Enviar o lembrete

1. Acesse **VENDAS > CREDIÁRIO > GESTÃO DE CREDIÁRIO**.
2. Use os filtros para escolher quem vai receber, por exemplo: **Vencem amanhã**, **Vencem nesta semana** ou **Vencem no mês que vem**.
3. Na linha do cliente, clique no ícone do **WhatsApp**.
4. Confira a mensagem e clique em **Iniciar conversa**.
5. No WhatsApp, envie a mensagem.
6. Repita para cada cliente da lista.

## Entendendo a tela

Em **CLIENTES > MARKETING > WHATSAPP** você também pode personalizar outras mensagens:

* **Aniversário:** parabéns para o cliente.
* **Cupom de venda:** texto enviado junto com o cupom após a compra.
* **Romaneio de bag** e **romaneio de live**.
* **Pós-venda:** para clientes que compraram no mês, no ano ou nos últimos X dias.
* **Nota fiscal**, **clientes que não compram há 90 dias** e **comprovante de pagamento do crediário**.

{% hint style="warning" %}
O aplicativo do WhatsApp instalado no computador pode apresentar problemas de versão e deixar de enviar algumas mensagens. Isso não é um erro da Phibo. Se acontecer, desinstale o aplicativo e use o **WhatsApp Web**, no navegador.
{% endhint %}
