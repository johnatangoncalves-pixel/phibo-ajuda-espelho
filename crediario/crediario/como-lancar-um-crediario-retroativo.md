# Como lançar um crediário retroativo

{% hint style="warning" %}
🔧 **Nota interna – remover antes de publicar:** texto escrito a partir do vídeo. Conferir na tela do sistema os trechos marcados [confirmar na tela].
{% endhint %}

Use este processo para lançar na Phibo crediários antigos que ainda estão em aberto, mesmo quando você não tem mais o produto.

{% hint style="info" %}
**Antes de começar:** os clientes precisam estar cadastrados. Tenha à mão uma lista (planilha ou caderno) com as parcelas, valores e vencimentos de cada cliente.
{% endhint %}

## Passo a passo

1. Acesse **PDV > REGISTRAR VENDA**.
2. Informe o **vendedor**, a **data da venda** e o **cliente**.
3. Lance o **produto padrão** (genérico) e, no campo **Valor**, informe o valor total da venda ou das parcelas [confirmar na tela].
4. Clique em **Efetuar recebimento**, escolha **Crediário** e informe o vencimento e o número de parcelas.
5. Conclua a venda.

### Duas formas de lançar

* **Uma venda por compra:** lance cada venda com a data original e suas parcelas. Fica mais organizado, mas dá mais trabalho.
* **Uma venda só:** use a data mais antiga, lance o valor total e, no recebimento, inclua várias formas de pagamento em crediário, uma para cada vencimento ou grupo de parcelas. A Phibo mostra quanto falta a cada lançamento.

### Conferir o lançamento

6. Para conferir, acesse **VENDAS > CREDIÁRIO > ANÁLISE POR CLIENTE** e busque o cliente. Todas as parcelas aparecem com valores e vencimentos.

{% hint style="warning" %}
* Se o produto padrão não aparecer, provavelmente sua parte fiscal já está ativa. Peça ao suporte o cadastro do produto padrão para lançar crediários retroativos.
* Com a parte fiscal ativa, não emita nota desses crediários: use o botão **Concluir venda sem NFC-e**. Se ele não aparecer, chame o suporte.
* Se não conseguir escolher a data de vencimento desejada ou faltar quantidade de parcelas, o suporte pode liberar.
{% endhint %}
