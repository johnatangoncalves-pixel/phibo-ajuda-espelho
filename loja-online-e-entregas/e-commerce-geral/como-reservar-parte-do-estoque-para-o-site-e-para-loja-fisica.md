# Como reservar parte do estoque para o site e para loja física

Assista o vídeo para visualizar detalhadamente o passo a passo:

{% embed url="<https://www.loom.com/share/268d61776c374d4b8401dbf48594746b>" %}

Ou, veja abaixo a orientação de como realizar a separação do estoque:

1 - Acesse a tela destacada abaixo para acessar os parâmetros da sua integração com o E-commerce:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FH4H1ed2sxC1oObI3l1h0%2Fimage.png?alt=media&amp;token=d50e58a7-6e00-4fe9-a1f5-032bd6312f67" alt=""><figcaption></figcaption></figure>

2- Em seguida, clique no botão “INTEGRAR AGORA” da plataforma que você usa:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FuAYElh9EDztt0EMDbqT7%2Fimage.png?alt=media&amp;token=2ff20a2e-b9a9-4776-bbf7-889071a47a60" alt=""><figcaption></figcaption></figure>

3- Clique na aba “PARÂMETROS” e ative o botão “RESERVAR ESTOQUE ECOMMERCE” e salve:

{% embed url="<https://prnt.sc/KywLeWgqyYCc>" %}

{% hint style="info" %}
Uma vez que ativada essa funcionalidade, todos os produtos precisarão desse ajuste na quantidade, ou seja, se já houverem produtos vinculados, será preciso editar cada um deles determinando o estoque do site e da loja física.
{% endhint %}
