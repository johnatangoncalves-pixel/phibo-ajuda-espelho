# Como integrar o Phibo com a Bagy

{% hint style="warning" %}
🔧 **Nota interna – remover antes de publicar:** texto escrito a partir do vídeo. Conferir na tela do sistema os trechos marcados [confirmar na tela].
{% endhint %}

Integre sua loja na Bagy com o Phibo para que o sistema e o site se conectem e troquem produtos e pedidos.

{% hint style="info" %}
**Antes de começar:** cada conta Bagy aceita apenas um CNPJ ou CPF. Por isso, você só pode integrar **uma** conta Phibo a **uma** conta Bagy. O Phibo não tem função multilojas para juntar estoques de várias lojas no mesmo site.
{% endhint %}

## Passo a passo

### Na Bagy

1. Acesse a **LOJA DE APLICATIVOS**.
2. Pesquise por **Phibo** e tecle Enter.
3. Clique em **Ver detalhes** e depois em **Instalar**. Aguarde o processamento, que pode levar alguns instantes.
4. A Bagy vai gerar um **token**. Clique no botão de copiar [confirmar na tela] para copiar o token exatamente como está. Você será levado ao sistema.
5. Faça login na conta Phibo que será integrada e clique em **Acessar**.

### No Phibo

1. Acesse **INÍCIO > CONFIGURAR MÓDULOS > INTEGRAÇÃO E-COMMERCE**.
2. Clique em **Bagy** e cole o token no campo indicado.
3. Clique em **Salvar**. A mensagem de token atualizado com sucesso vai aparecer.
4. Clique no botão **On** para testar a conexão. A mensagem deve indicar que a loja está conectada.

{% hint style="warning" %}
O token não pode ter nenhum espaço antes ou depois. Um espaço extra conta como mais um caractere e impede a integração. Confira antes de salvar.
{% endhint %}

Depois da integração

{% hint style="warning" %}
Integrar não envia os produtos automaticamente para o site. Você escolhe quais produtos quer publicar.
{% endhint %}

* Em **COMPRAS > GESTÃO DE ESTOQUE > CADASTRAR PRODUTOS** aparecem novas opções: **cadastrar**, **vincular**, **atualizar quantidade**, **desvincular** e **importar produtos** do site para o sistema.
* Os pedidos feitos no site caem no sistema para você finalizar e emitir as notas.
* Se você tiver o Melhor Envio conectado, também é possível emitir etiquetas de envio automaticamente.

Cada uma dessas funções tem um tutorial próprio. Peça ao suporte se precisar.
