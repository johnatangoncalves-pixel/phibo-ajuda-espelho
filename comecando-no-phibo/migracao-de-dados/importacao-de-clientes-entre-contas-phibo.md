# Importação de clientes entre contas Phibo

Copie os clientes de uma conta Phibo para outra exportando uma planilha de uma conta e importando na outra.

{% hint style="warning" %}
As telas de exportar e importar dados só funcionam das **19h10 até as 12h30** do dia seguinte. Entre 12h30 e 19h10 elas ficam bloqueadas por segurança.
{% endhint %}

## Passo a passo

### 1. Exportar da conta de origem

1. Na conta de onde os clientes vão sair, acesse **GESTÃO DE DADOS > CLIENTES > EXPORTAR DADOS**.
2. Clique no **botão verde**. Uma planilha será baixada.

A planilha já sai no formato exato para importação. Não é preciso abri-la nem alterá-la, mas você pode abrir para conferir os dados.

### 2. Importar na conta de destino

1. Na outra conta, acesse **GESTÃO DE DADOS > CLIENTES > IMPORTAR DADOS**.
2. Em **Arquivo**, selecione a planilha baixada (normalmente o arquivo mais recente da pasta Downloads).
3. Clique em **Validar**.
4. Clique em **Confirmar carga**.

### 3. Acompanhar a importação

1. Acesse **GESTÃO DE DADOS > GESTÃO DE IMPORTAÇÃO**.
2. Confira a linha da sua carga: data, nome da planilha, usuário, tipo de carga (clientes) e status.
3. Quando o status mudar de **Pendente** para **Concluído**, os clientes já estarão na conta. Confira em **CLIENTES > LISTAR CLIENTES**.

{% hint style="info" %}
A importação pode levar até o dia seguinte, dependendo do tamanho da planilha e da internet.
{% endhint %}
