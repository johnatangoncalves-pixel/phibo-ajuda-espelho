# Como utilizar as mensagens dinâmicas no PhiboZap

{% embed url="<https://youtu.be/UdHP5hwrXMA>" %}

🚀 No vídeo acima mostramos uma funcionalidade INCRÍVEL do PhiboZap: as Mensagens Dinâmicas!\
\
Com esse recurso, você consegue criar mensagens muito mais naturais e humanizadas, alternando automaticamente partes do texto durante os disparos 💬✨

Ou seja: ao invés de todos os clientes receberem exatamente a mesma mensagem, o sistema cria combinações automáticas utilizando as opções que você cadastrar 👇

Além de deixar a comunicação mais profissional e personalizada, a variação das mensagens também ajuda a tornar os envios mais naturais durante as campanhas ✅

Exemplo prático de mensagem dinâmica de aniversário 🎂

{ Oi | Olá | Eaí | Fala }, %xnome% { tudo bem? | como você está? | como vai? }

{ Hoje, dia %xdia%/%xmes%, é uma data muito especial 🎉 | Passando neste %xdia%/%xmes% para te desejar um feliz aniversário 🎂 | Não poderíamos deixar seu aniversário de %xdia%/%xmes% passar em branco }

{ Que seu dia seja incrível | Muitas felicidades pra você | Desejamos muita saúde e sucesso }

{ Aproveite bastante seu dia | Curta muito essa data especial 🎊 | Tudo de melhor sempre }

————————————————————

{ Oi | Olá }, %xnome% { temos uma surpresa pra você 🎁 | viemos te dar os parabéns 🎉 | hoje o dia é seu }

{ Feliz aniversário neste dia %xdia%/%xmes%! | Parabéns pelo seu dia 🎂 | Muitas felicidades nesta data especial }

{ Que nunca faltem motivos pra sorrir | Que seu novo ciclo seja incrível | Desejamos muito sucesso pra você }

{ Aproveite bastante | Tenha um excelente aniversário | Curta muito seu dia 🎉 }

————————————————————

{ Opa | Olá | Ei }, %xnome% { tudo certo? | como vai? }

{ Passando rapidinho pra desejar um feliz aniversário neste %xdia%/%xmes% 🎉 | Hoje, %xdia%/%xmes%, é seu grande dia 🎂 | Queremos te parabenizar pela sua data especial }

{ Que essa nova fase venha cheia de conquistas | Muitas bênçãos pra você | Muito sucesso e felicidade }

{ Abraços da equipe ❤️ | Conte sempre conosco | Aproveite muito seu aniversário }

Com as Mensagens Dinâmicas do PhiboZap, suas automações ficam muito mais inteligentes, profissionais e naturais 🚀
