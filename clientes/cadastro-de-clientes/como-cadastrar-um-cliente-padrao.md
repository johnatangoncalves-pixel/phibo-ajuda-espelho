# Como cadastrar um cliente padrão

{% hint style="success" %}
**Artigo unificado:** substitui “Como cadastrar um Cliente Padrão” (https://ajuda.phibo.site/primeiros-passos/primeiros-passos-treinamento-2/como-cadastrar-um-cliente-padrao).
{% endhint %}

Embora seja muito importante para as vendas ter os dados do cliente, sabemos que muitas vezes os clientes estão com pressa para fazer cadastro ou apenas não desejam realiza-lo.

Para lançar as vendas no sistema Phibo é necessário que haja um cliente vinculado a essa transação. Caso a pessoa não queira fazer cadastro, utilizaremos então o **Cliente Padrão.**

Para cadastrar um Cliente Padrão, primeiro vá em CLIENTES > CADASTRAR CLIENTE:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FyV66Rij0tpmNPjROL9Os%2Fimage.png?alt=media&amp;token=9410a3d9-9376-43bc-8a1b-517b3de9791f" alt=""><figcaption></figcaption></figure>

Preencha o campo de "Celular" com "(00) 00000-0000" e os demais campos conforme consta na imagem abaixo. Por fim, clique em "Salvar".

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FpbaGnz2sNO0lu8w7r5aO%2Fimage.png?alt=media&amp;token=9c230984-61d8-44c5-98ec-4eb9aecd4a74" alt=""><figcaption></figcaption></figure>

Você poderá buscar facilmente esse Cliente Padrão nas telas onde o cliente é requisitado como filtro, sempre informando o número "(00) 00000-0000" no campo "**Número Celular**" e teclando "TAB":

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2Ffnw51Dgw6spUGOPKsLt6%2Fimage.png?alt=media&amp;token=f318e34e-0e52-4c34-ade4-7069d1098d42" alt=""><figcaption></figcaption></figure>
