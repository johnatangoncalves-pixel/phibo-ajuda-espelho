# Como baixar os arquivos das notas do mês anterior (XML)

**Para baixar o arquivo XML das notas emitidas no mês anterior, assista o vídeo completo ou veja abaixo o passo a passo:**

{% embed url="<https://www.loom.com/share/f43fc74938a34dc6aa0e202830f2d7de>" %}

**Veja abaixo o passo a passo detalhado:**

**1 – Acesse **INICIO > CONFIGURAR MODULOS > NOTA FISCAL ELETRÔNICA > REENVIAR XML NOTA FISCAL**:**

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FRAXfqwlAYoAS7M3q5TEd%2Fimage.png?alt=media&amp;token=87914ac1-841c-4287-aa99-4ed9ffb31371" alt=""><figcaption></figcaption></figure>

**2- Ao acessar a tela clique no botão cinza DOWNLOAD ARQUIVO ZIP XML:**

{% embed url="<https://prnt.sc/xUnA89o3J0eS>" %}

**3- Feito isso basta selecionar modelo por modelo de nota fiscal emitida e clicar em “Download ZIP XML”**

{% embed url="<https://prnt.sc/fLk9s5WgifJf>" %}

**4- O sistema vai baixar uma pasta para cada modelo de nota emitida, e quando não houver nota emitida para o modelo selecionado, será retornada a mensagem abaixo:**

{% embed url="<https://prnt.sc/veNP9Ft4jdvb>" %}

**5- Por fim, basta buscar as pastas baixadas e encaminhar para seu contador.**
