# Como reenviar o XML das notas para o e-mail do contador

Assista o vídeo abaixo para ver detalhadamente como realizar a solicitação do reenvio de xmls de qualqier período para seu contador :

{% embed url="<https://www.loom.com/share/5ebaed3048034e0c9a3d3208134ff3c8>" %}

Ou veja abaixo detalhadamente como solicitar:

#### 1 – Acesse INÍCIO > CONFIGURAR MODULOS > NOTA FISCAL ELETRÔNICA > REENVIAR XML

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FzKX8dOyAd7vb00ic9Vw3%2Fimage.png?alt=media&amp;token=6c04a7e7-0705-4388-bc3b-20898d7d8bfa" alt=""><figcaption></figcaption></figure>

#### 2- Clique no botão NOVA SOLICITAÇÃO:

{% embed url="<https://prnt.sc/RWCtoKR1brto>" %}

#### 3- Informe o modelo ( NFCE modelo 65 ou NFE modelo 55 ) , o número de série da nota, número inicial e final clique no botão SALVAR.

Obs: para consultar o modelo, série e o primeiro e último número do período desejado, acesse <mark style="background-color:yellow;">**VENDAS > CONSULTA VENDAS > GESTAO DE NF**</mark>, filtre o período e clique no botão verde (EXPORTAR TODAS AS NOTAS FISCAIS). Será gerada uma planilha com todas as informações necessárias para essa solicitação:

{% embed url="<https://prnt.sc/JWR5v2gPZgjq>" %}

#### 4- Por fim, entre em contato com o Suporte da Phibo através do número 55 (31) 7159-1121 e solicite o reenvio da solicitação realizada.

{% hint style="danger" %}
O XML (documento fiscal eletrônico) das notas fiscais informadas só serão reenviados mediante a solicitação no suporte! Para isso, basta entrar em contato informando que realizou o pedido reenvio e precisa que o suporte autorize.
{% endhint %}
