# Como baixar o arquivo de uma nota cancelada ou inutilizada (XML)

## Para salvar o xml  das notas de venda inutilizadas ou canceladas acesse VENDAS > CONSULTA VENDAS > GESTAO DE NOTA FISCAL:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FnHR7eTWSRDvxb55MEpZY%2Fimage.png?alt=media&amp;token=ca8ff47b-adca-4bc0-90d3-add6bea9b32d" alt=""><figcaption></figcaption></figure>

## Defina o período desejado e ao final tela consulte as notas com status específico (pendentes, canceladas ou inutilizadas).

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FvDvy3pJUH2CJiNUGSDX5%2Fimage.png?alt=media&amp;token=9ad5ce58-fcae-45db-be3a-2315435b9154" alt=""><figcaption></figcaption></figure>
