# Como corrigir dados de uma nota já emitida (carta de correção)

{% hint style="success" %}
**Artigo unificado:** substitui “Como emitir carta de correção para NF-e de Devolução” (https://ajuda.phibo.site/sobre-o-sitema/fiscal/como-fazer-uma-nota-de-devolucao-no-phibo-2).
{% endhint %}

{% hint style="info" %}
IMPORTANTE ❗

A Carta de Correção pode ser utilizada para ajustar algum erro ocorrido na emissão de um nota fiscal, desde que o erro *NÃO* esteja relacionado os itens abaixo:

👉 As variáveis que determinam o valor do *imposto* tais como: base de cálculo, alíquota, diferença de preço, quantidade, valor da operação ou da prestação;

👉 A correção de dados cadastrais que implique mudança do remetente ou do destinatário;

👉 A data de emissão ou de saída.
{% endhint %}
