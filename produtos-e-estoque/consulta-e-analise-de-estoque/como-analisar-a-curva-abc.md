# Como ver os produtos que mais faturam (Curva ABC)

Para consultar o relatório de curva ABC do seu estoque, vá na seguinte tela **COMPRAS > GESTÃO ESTOQUE > CURVA ABC**:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FDLun8NxTkE7z84S8UXKb%2Fimage.png?alt=media&amp;token=beadc133-78dd-4b0d-97d7-498d2b2c75e2" alt=""><figcaption></figcaption></figure>

Na primeira aba da tela, você poderá consultar o relatório por fornecedor, visão global, que seria o formato resumido desse relatório:

{% hint style="warning" %}
Você poderá filtrar por mês ou período específico, utilizando o campo destacado na imagem.
{% endhint %}

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FpwEukSGQdxIuVKNn150K%2Fimage.png?alt=media&amp;token=bee014ab-a938-4dbe-a041-d0efba3ae0ea" alt=""><figcaption></figcaption></figure>

Caso queira fazer uma consulta mais detalhada de cada fornecedor, basta clicar no botão "Visão Detalhada":

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FbFGujsWOvMTtbs9F0h17%2Fimage.png?alt=media&amp;token=46350629-7214-49af-b44d-7f3b383d4405" alt=""><figcaption></figcaption></figure>

Na aba "Categoria", você poderá consultar o relatório de curva ABC por categoria cadastrada:

{% hint style="info" %}
Clique no botão destacado na imagem para abrir a visão detalhada de cada categoria.
{% endhint %}

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FNVzxG030bdXN9hphvw0C%2Fimage.png?alt=media&amp;token=99665d23-54b3-429d-909a-0d0e644eb2ca" alt=""><figcaption></figcaption></figure>
