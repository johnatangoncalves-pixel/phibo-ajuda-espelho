# 📖 Glossário: termos do sistema

Não sabe o que significa uma palavra que aparece no Phibo? Veja aqui, em ordem alfabética.

| Termo | O que é | Saiba mais |
|---|---|---|
| **Abertura de caixa** | Valor em dinheiro que fica no caixa no início do dia (o troco). | [Ver artigo](../caixa-e-financeiro/caixa-diario/como-fazer-abertura-suprimento-e-sangria-de-caixa.md) |
| **Bag Delivery** | Sacola com peças enviada para a cliente experimentar em casa. Ela fica com o que gostar e devolve o resto. | [Ver artigo](../bags-delivery/bags-delivery/como-fazer-uma-venda-por-bag-delivery.md) |
| **Carta de correção (CC-e)** | Documento que corrige alguns dados de uma NF-e já autorizada, sem cancelar a nota. | [Ver artigo](../notas-fiscais/corrigir-cancelar-e-inutilizar/como-emitir-carta-de-correcao-de-nf-e-venda-ou-devolucao.md) |
| **Cashback** | Parte do valor da compra que volta para a cliente como saldo para usar numa próxima compra. | [Ver artigo](../fidelizacao-e-marketing/cashback/como-configurar-o-cashback.md) |
| **Certificado digital** | Arquivo (modelo A1) que identifica a empresa e é obrigatório para emitir notas fiscais. | [Ver artigo](../notas-fiscais/configuracao-fiscal/como-incluir-o-certificado-digital.md) |
| **Cliente padrão** | Cadastro genérico usado quando a cliente não quer se identificar na venda. | [Ver artigo](../clientes/cadastro-de-clientes/como-cadastrar-um-cliente-padrao.md) |
| **Coleção** | Agrupamento das peças por estação ou lançamento (ex.: Verão 2026). | [Ver artigo](../produtos-e-estoque/cadastros-auxiliares-grades-cores-categorias/como-cadastrar-colecoes.md) |
| **Crediário** | Venda parcelada direto com a loja, em que a cliente paga as parcelas nas datas combinadas. | [Ver artigo](../crediario/crediario/como-fazer-a-gestao-do-crediario.md) |
| **Curva ABC** | Relatório que separa os produtos pela importância nas vendas: A (vendem mais), B e C (vendem menos). | [Ver artigo](../produtos-e-estoque/consulta-e-analise-de-estoque/como-analisar-a-curva-abc.md) |
| **Despesa x Compra** | Despesa é conta geral da loja (aluguel, luz, salários). Compra é a mercadoria comprada do fornecedor para revender. | [Ver artigo](../caixa-e-financeiro/despesas-e-contas-a-pagar/diferenca-entre-despesas-e-compras.md) |
| **DRE** | Demonstrativo de Resultado: mostra se a loja teve lucro ou prejuízo no período. | [Ver artigo](../caixa-e-financeiro/visao-geral-e-relatorios/como-analisar-o-dre.md) |
| **EAN** | O número do código de barras de um produto. | [Ver artigo](../produtos-e-estoque/cadastro-de-produtos/como-cadastrar-o-mesmo-produto-com-codigos-de-barras-ean-diferentes-por-tamanho.md) |
| **Fluxo de caixa** | Lista de todas as entradas e saídas de dinheiro da loja por data. | [Ver artigo](../caixa-e-financeiro/visao-geral-e-relatorios/como-fazer-a-analise-de-listar-fluxo-de-caixa.md) |
| **Giro de estoque** | Mostra quais produtos vendem mais rápido e quais estão parados. | [Ver artigo](../produtos-e-estoque/consulta-e-analise-de-estoque/como-analisar-giro-de-estoque.md) |
| **Grade** | Conjunto de tamanhos de um produto (ex.: P, M, G ou 36 a 44). | [Ver artigo](../produtos-e-estoque/cadastros-auxiliares-grades-cores-categorias/como-configurar-grades-cores-e-parametros-de-estoque.md) |
| **Inutilização de nota** | Aviso à Sefaz de que uma numeração de nota não será usada (quando a numeração pula). | [Ver artigo](../notas-fiscais/corrigir-cancelar-e-inutilizar/como-inutilizar-uma-nota-fiscal.md) |
| **Inventário** | Contagem das peças da loja para conferir se o estoque do sistema bate com o físico. | [Ver artigo](../produtos-e-estoque/inventario-e-transferencias/conferencia-de-estoque-inventario.md) |
| **NF-e (modelo 55)** | Nota fiscal eletrônica usada em vendas online, devoluções a fornecedor e transferências. | [Ver artigo](../notas-fiscais/emitir-nota-de-venda-nfc-e-nf-e/como-emitir-nf-e-modelo-55-para-e-commerce.md) |
| **NFC-e (modelo 65)** | Nota fiscal do consumidor, o antigo cupom fiscal, usada nas vendas da loja física. | [Ver artigo](../notas-fiscais/emitir-nota-de-venda-nfc-e-nf-e/como-emitir-nfc-e-modelo-65.md) |
| **PhiboZap** | Ferramenta do Phibo para enviar mensagens automáticas de WhatsApp para as clientes. | [Ver artigo](../fidelizacao-e-marketing/phibozap/o-que-e-o-phibozap.md) |
| **Produto padrão** | Produto genérico usado para lançar uma venda de peça que ainda não está cadastrada. | [Ver artigo](../vendas-no-pdv/fazer-uma-venda/o-que-e-o-produto-padrao-e-para-que-serve.md) |
| **Promissória** | Documento impresso que a cliente assina comprometendo-se a pagar o crediário. | [Ver artigo](../crediario/crediario/como-gerar-a-promissoria-de-um-crediario.md) |
| **Romaneio** | Lista impressa das peças que foram dentro da bag. | [Ver artigo](../bags-delivery/bags-delivery/como-montar-uma-bag-delivery-e-emitir-romaneio.md) |
| **Sangria** | Retirada de dinheiro do caixa durante o dia (ex.: para guardar no cofre). | [Ver artigo](../caixa-e-financeiro/caixa-diario/como-fazer-abertura-suprimento-e-sangria-de-caixa.md) |
| **Sefaz** | Secretaria da Fazenda do estado, que autoriza (ou rejeita) as notas fiscais. | [Ver artigo](../notas-fiscais/erros-e-rejeicoes-da-sefaz/o-que-fazer-quando-a-nota-e-rejeitada.md) |
| **Suprimento** | Entrada de dinheiro no caixa durante o dia (ex.: reforço de troco). | [Ver artigo](../caixa-e-financeiro/caixa-diario/como-fazer-abertura-suprimento-e-sangria-de-caixa.md) |
| **TEF** | Integração do Phibo com a maquininha: o valor vai direto para a máquina, sem digitar. | [Ver artigo](../impressoras-etiquetas-e-tef/tef/como-usar-o-tef.md) |
| **Variação** | Cada combinação de tamanho e cor de um mesmo produto. | [Ver artigo](../produtos-e-estoque/variacoes/como-cadastrar-as-variacoes-de-um-produto-no-sistema.md) |
| **XML** | Arquivo digital da nota fiscal. Usado para dar entrada nas compras e enviar ao contador. | [Ver artigo](../compras-e-fornecedores/entrada-de-notas-de-compra/como-cadastrar-produtos-pelo-xml-da-nota-de-compra.md) |
