# Como cadastrar fornecedores

## Para cadastrar um Fornecedor no sistema Phibo, primeiramente vá em COMPRAS > CADASTRAR FORNECEDOR:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FV1ILmGH8HDvF5aInhJWL%2Fimage.png?alt=media&amp;token=f3dbcb96-57ea-493c-87f0-67ac6adc51dd" alt=""><figcaption></figcaption></figure>

## Na primeira aba, preencha com os dados gerais desse Fornecedor. Somente o campo NOME é obrigatório, mas é recomendável colocar o e-mail ou telefone caso tenha essas informações.<br>

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FLDRsQ0ueug1KYhozRJT8%2Fimage.png?alt=media&amp;token=bd41e2eb-8e04-4709-ae85-3d54a66e71f7" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
DICA: Use o campo Observação para colocar anotações específicas desse Fornecedor, como produtos que venderam bem e você gostaria de comprar novamente, produtos que não valem a pena se comprados novamente, etc...
{% endhint %}

## Na aba MARCAS, coloque as marcas que você compra com esse fornecedor específico (se houver):

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FpmSgfx8BPwmD6tdAPrMw%2Fimage.png?alt=media&amp;token=3e4cfbdb-db85-4f97-8f55-cf54bb1db66f" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
IMPORTANTE: Se o Fornecedor em questão não tem marcas em seus produtos, basta deixar uma marca com o mesmo nome desse fornecedor para representa-lo nos cadastros dos produtos.
{% endhint %}

## Por fim, na aba DADOS COMPLEMENTARES, preencha com os dados gerais desse Fornecedor. Esses campos NÃO SÃO OBRIGATÓRIOS, porém são necessários caso você precise emite alguma nota de devolução a esse fornecedor:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2FWZKRbItYpxKqcjeDBQwN%2Fimage.png?alt=media&amp;token=d5efde3a-d7cc-4f43-9664-3d09bce58475" alt=""><figcaption></figcaption></figure>

## Com todas as abas devidamente preenchidas, basta clicar no botão salvar na parte inferior direita:

<figure><img src="https://1136259996-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F-MbXdm46cDzB-VCuUzq9%2Fuploads%2F8aggVQp5dASdmIpC1DaH%2Fimage.png?alt=media&amp;token=37956a8e-52b7-4fcc-8d8f-66cc5c2c7773" alt=""><figcaption></figcaption></figure>
