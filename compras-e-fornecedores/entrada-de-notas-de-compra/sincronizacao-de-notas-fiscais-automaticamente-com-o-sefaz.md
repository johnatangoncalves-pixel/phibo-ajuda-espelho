# Como receber as notas de compra automaticamente da Sefaz

Com o manifesto de notas, o sistema busca automaticamente na Sefaz as notas emitidas para o seu CNPJ. Você não precisa mais procurar o XML do fornecedor no e-mail.

{% hint style="info" %}
**Antes de começar:** a funcionalidade é exclusiva do **plano Ouro**. Também é preciso ter o fiscal ativo ou, pelo menos, o certificado digital inserido no sistema. Para mudar de plano ou ativar o certificado, fale com o suporte.
{% endhint %}

## Passo a passo

### Ativar a sincronização

1. Acesse **INÍCIO > CONFIGURAR MÓDULOS > NOTA FISCAL > PARÂMETROS**.
2. Clique na aba **Notas de entrada**.
3. Se a opção estiver em vermelho (desabilitada), clique para ativar.

{% hint style="warning" %}
Se a aba **Notas de entrada** não aparecer, provavelmente o fiscal não está ativo ou o certificado não foi inserido. Fale com o suporte.
{% endhint %}

### Importar uma nota

1. Acesse **COMPRAS > NOTA FISCAL > LER ARQUIVO XML**.
2. Veja a lista de notas emitidas para o seu CNPJ, com data e chave de acesso.
3. Identifique a nota e clique em **Carregar**.
4. Vá até **Validar produtos** e valide a nota normalmente.

{% hint style="info" %}
A nota só vai para **Validar produtos** depois que você clicar em **Carregar**.
{% endhint %}

Sem a sincronização, o processo continua manual: em **COMPRAS > NOTA FISCAL > LER ARQUIVO XML**, clique em **Buscar arquivo** e anexe o XML enviado pelo fornecedor.
