# Como baixar e acessar o AnyDesk

{% hint style="warning" %}
🔧 **Nota interna – remover antes de publicar:** texto escrito a partir do vídeo. Conferir na tela do sistema os trechos marcados [confirmar na tela].
{% endhint %}

O AnyDesk é o programa que o suporte da Phibo usa para acessar seu computador remotamente e ajudar a resolver problemas no sistema.

## Passo a passo

1. Abra o Google Chrome e pesquise **download AnyDesk**.
2. Clique no primeiro resultado, o site oficial do AnyDesk (anydesk.com).
3. Clique em **Baixar agora** (o botão também pode aparecer como **Faça o download**).
4. Clique no ícone de downloads do Chrome, no canto superior da tela, e depois no ícone de pasta para abrir a pasta de downloads.
5. Dê dois cliques no arquivo do AnyDesk para abrir.
6. Se o computador pedir instalação, clique em **Instalar AnyDesk** e depois em **Aceito e quero instalar** [confirmar na tela].
7. Se o Windows perguntar se deseja permitir, clique em **Sim**.
8. Feche a tela de boas-vindas no **X**.
9. Copie o número que aparece na tela. Esse é o número do seu computador.
10. Envie esse número para o suporte pelo WhatsApp.
11. Quando o suporte acessar, vai aparecer uma janela com um botão verde e um vermelho. Clique em **Aceitar** (verde).

{% hint style="info" %}
Esse passo a passo é para Windows. Se você usa Mac, pesquise **AnyDesk para Mac** e baixe a versão para Mac.
{% endhint %}

{% hint style="warning" %}
Cada computador tem um número diferente. Sempre envie o número que aparece no seu AnyDesk.
{% endhint %}
